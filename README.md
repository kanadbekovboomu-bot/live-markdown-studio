# 📝 Live Markdown Studio

Быстрый онлайн-редактор Markdown с рендерингом в реальном времени.

## ✨ Особенности
- ⚡ Двухоконный интерфейс с синхронным предпросмотром
- 🛠️ Панель инструментов форматирования (жирный, курсив, заголовки, списки, ссылки, код)
- 📊 Подсчет слов, символов и примерного времени чтения
- 💾 Автосохранение черновика в `localStorage`
- 📥 Экспорт в файл `.md` и копирование чистого сгенерированного HTML
